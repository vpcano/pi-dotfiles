# pi agent config

User configuration for [pi](https://github.com/earendil-works/pi-coding-agent), my terminal coding agent.

- `settings.json` — installed packages (e.g. pi-interactive-subagents)
- `extensions/` — custom extensions: bash-guard, browser, web-fetch, web-search, ask-user-question, custom-header
- `skills/` — custom skills: pdf-reader, web-debug, youtube-transcript

Not tracked: credentials (`auth.json`, `extensions/web-search/auth.json`), the managed install (`install/`, `bin/`), and runtime caches (`sessions/`, `tmp/`, `models-store.json`, `git/`).
